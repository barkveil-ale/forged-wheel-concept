# Forged Wheel Concept

3D forged wheel design project featuring CAD modeling and engineering visualization.

## Overview

This project showcases a custom forged wheel concept designed using AutoCAD 3D. The design focuses on a modern multi-spoke performance style with detailed engineering visualization and technical modeling.

## Features

- 3D CAD wheel modeling
- Performance-inspired forged wheel concept
- Engineering visualization
- Technical drawing included
- STL and IGES export files
- High-resolution renders

## Software Used

- AutoCAD 2021

## Files Included

```plaintext
cad/
├── wheel_design.dwg
├── wheel_design.stl
└── wheel_design.igs
```

## Technical Drawing

Detailed wheel dimensions and engineering drawings are available in the `technical-drawing` folder.

## Design Specifications

- Wheel Type : Forged Alloy Concept
- Design Style : Multi-Spoke
- Modeling Type : 3D CAD
- Visualization : Engineering Render
